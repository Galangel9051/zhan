# SMTP 邮箱预设

设置 → 邮件通知支持 QQ 邮箱、Gmail 和自定义。

| 预设 | 服务器 | 端口 | 加密方式 |
| --- | --- | --- | --- |
| QQ 邮箱 | smtp.qq.com | 465 | 隐式 TLS |
| Gmail | smtp.gmail.com | 587 | STARTTLS |
| 自定义 | 手动填写 | 手动填写 | 手动选择 |

选择预设后只显示连接参数摘要，减少重复填写；选择自定义时显示服务器、端口和 TLS 输入。当前页面会保留切换前的自定义连接参数，切换回自定义可以继续编辑。

QQ 邮箱需先开启 SMTP 服务，再填写授权码。[QQ 邮箱官方授权码说明](https://help.mail.qq.com/detail/106/985)。Gmail 使用应用专用密码，需要开启两步验证，且部分组织或安全策略可能限制该功能。[Google 官方应用专用密码说明](https://support.google.com/mail/answer/185833?hl=zh-Hans)、[Gmail 官方 SMTP 参数](https://developers.google.com/workspace/gmail/imap/imap-smtp)。

切换到不同连接参数会清空本次填写的密码，并要求重新填写对应凭据。服务器、端口、TLS 和用户名与已保存配置一致时，可以留空使用已保存密码。

“发给自己”可快捷填入发件人与收件人。“发送测试邮件”使用当前配置进行测试，不会自动保存。确认后点击“保存配置”。

## 开启与关闭

SMTP 配置上方的“邮件通知”开关控制全局邮件发送。切换后点击“保存配置”生效。关闭会收起配置项并禁用测试发送，同时保留服务器、邮箱、收件人和已保存的密码；重新开启后可继续使用。

全局关闭时，即使某个项目勾选失败告警，也不会发送邮件或产生失败发送记录。旧配置没有开关字段时，已配置服务器的邮箱保持启用，尚未配置的邮箱默认关闭。导入导出会保留开关状态。
