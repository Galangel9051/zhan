# 容器资源与自定义列

「项目与容器」采用 Compose 项目 → 容器两层表格。点击项目名称左侧箭头直接展开容器，运行状态、资源、镜像和端口等信息显示在容器行的对应列中。

## 资源数据

运行中容器每 5 秒采样一次，来自宿主机的 `docker stats --no-stream`；仅采样已导入项目中的容器。页面隐藏时暂停周期刷新，重新可见后恢复。项目行显示其运行容器的合计。

支持 CPU、内存使用量、容器内存上限、网络接收/发送累计字节、磁盘读取/写入累计字节和 PIDs（进程/线程数）。还可以显示容器 ID、镜像、端口、启动时间和重启次数。

- CPU 采用 Docker 的多核累计百分比，可能超过 100%。
- 内存统计沿用 Docker CLI 的口径；多个容器的内存上限不直接相加，避免把共享的宿主机上限重复计入。
- 网络和磁盘 I/O 是 Docker 报告的累计计数，不是每秒速率，也不是磁盘空间占用。
- 停止、未采样或平台不支持的指标显示「—」。部分容器采样缺失时，合计会标记为「部分采样」。
- 资源采样失败不会修改容器状态，也不会阻止启停操作。

项目详情的「服务与容器」页同样显示服务和容器的资源摘要。详见 [Docker stats 官方说明](https://docs.docker.com/reference/cli/docker/container/stats/)。

## 自定义表头

点击「列设置」：

1. 勾选需要显示的列；名称和操作列始终保留。
2. 用前移、后移按钮调整顺序。
3. 输入列宽，按回车或离开输入框后应用。
4. 桌面端也可以拖拽表头分隔线；双击分隔线恢复该列默认宽度，方向键每次调整 10 px。
5. 点击「恢复默认」恢复全部默认列、顺序和宽度。

显示偏好保存在当前浏览器，刷新后继续使用；不会写进服务器配置或配置导出文件。浏览器禁止存储时，会提示设置仅在本次使用期间有效。手机端使用卡片布局，仍遵循列的显隐和顺序；列宽用于桌面表格。

## API

`GET /api/v1/containers/stats` 要求管理员会话，返回 `sampled_at`、以完整容器 ID 为键的 `containers` 和 `unavailable_count`。资源字段中不可用的值为 `null`，流量、内存和 I/O 的数值单位均为字节。

## 移动端布局

移动端使用紧凑项目卡片。展开项目后，容器以缩进、柔和分隔线和不同背景排列在项目下方，默认显示状态、CPU、内存及已发布端口。项目的 Git、最近任务和容器的启动时间等已选列，点击“详细信息”展开查看。容器不会显示不适用的 Git、最近任务空白项。

列设置仍控制信息是否可见；桌面端按表格显示，移动端将次要信息折叠，不改变已保存的列偏好。
