# Git 提交树

项目详情的「Git 版本追踪」显示绑定项目的真实提交历史，连线表示父提交关系，支持合并与分叉。每条记录显示提交说明、作者、时间和短版本号，并标记本地 HEAD、最近检测到的远程版本、最近成功部署和最近尝试部署的位置。

提交树每 15 秒刷新，也可以手动刷新。页面仅读取本机 Git 对象，不执行 fetch、合并、切换分支或修改工作区。远程位置优先使用最近检查记录；还没有检查记录时，使用本机 origin 分支记录，并明确标注来源。

远程提交对象已存在时，显示本地领先、落后或分叉的提交数量。尚未获取远程历史时不推测数量，而是显示提示。工作区有修改、当前分支与绑定分支不一致或处于分离 HEAD 时，也会显示提示。

最多显示最近 50 个提交。尚未获取或超出范围的部署版本会单独列出，不绘制虚构的连接线。未绑定 Git 分支的项目显示绑定提示。
